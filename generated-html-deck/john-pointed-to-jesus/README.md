# John Pointed to Jesus

Offline-friendly 16:9 teaching deck for The Gospel Project: Kids, Unit 21, Session 4. The proposed age version is Younger Kids.

## Source and content notes

- Ministry Grid session: [John Pointed to Jesus](https://ministrygrid.lifeway.com/#/curriculum/TGP/Kids/session/bff2d298-c371-4f07-9ef6-1637d7ad8ee0/issue/e8a22369-5ebf-4048-9c55-3fb50fa61c68)
- Reviewed: 2026-10-31
- Content basis: the visible Ministry Grid overview, which connects John's witness to belief in Jesus as Messiah, eternal life, and pointing others to Jesus.
- Visual basis: the lesson page's source illustration, stored locally in `assets/john-pointed-to-jesus-story.png`.
- The Bible passage, key passage reference, and official Big Picture answer were not visible in the accessible overview. The leader guide and poster downloads were listed, but their contents were not readable during review. The deck leaves those references out rather than guessing.
- The optional source videos and audio are omitted so the deck stays lightweight and works offline.

## Launch

Open `index.html` in a modern browser. For local browser review, run a simple static server from this folder:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000/`.

## Controls

- `←` / `→`: previous or next slide
- `Space`: next slide
- `Home` / `End`: first or last slide
- Click or tap the reveal buttons; focused buttons also open with `Enter` or `Space`
- Direct slide links use `#slide=6`
- Optional presenter notes are off by default. Open `?presenter=1` in the URL to show the Leader notes control.

The final slide is a short read-aloud prayer based on the lesson overview. The exact Bible passage and key passage should be added if the leader guide becomes available.
