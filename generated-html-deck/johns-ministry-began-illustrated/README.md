# John's Ministry Began

Interactive HTML teaching deck for The Gospel Project: Kids, Unit 20, Session 1.

## Source

- Lifeway Ministry Grid lesson: `John's Ministry Began`
- Bible passage: Matthew 3; Mark 1; Luke 3; John 1
- Key passage: John 1:14
- Big Picture Question: Is Jesus God or a human?
- Story Point: John prepared the way for Jesus.
- Source reviewed: 2026-09-13

The deck follows the shared story content in the Younger Kids and Older Kids leader guides, with wording simplified for a small group of children. The lesson's optional videos and audio are intentionally omitted so the deck works offline.

## Launch

Open `index.html` in a modern browser. The deck is self-contained apart from the local images in `assets/`.

- `←` / `→`: previous or next slide
- `Home` / `End`: first or last slide
- `Space`: next slide
- Click, tap, `Enter`, or `Space` on a yellow question button: reveal its answer cue

The deck uses the source-provided Bible story and poster artwork downloaded through the authenticated Lifeway lesson page.
