# John's ministry began — HTML teaching deck

Offline-friendly 16:9 teaching deck for The Gospel Project: Kids.

## Source

- Session reference: Ministry Grid curriculum link supplied by the user
- Lesson theme: John's ministry began
- Bible focus: Luke 3:1-18; Matthew 3; Mark 1

## Launch

Open `index.html` in a browser or serve this folder from a local static server:

```bash
cd /Users/wayne/Repo/github/commercial/ministrygrid-html-deck/generated-html-deck/johns-ministry-began
python3 -m http.server 8000
```

Then open `http://localhost:8000/`.

## Controls

- `←` / `→`: previous or next slide
- `Space`: next slide
- `Home` / `End`: first or last slide
- Click or tap reveal buttons; focused buttons also open with `Enter` or `Space`

The deck is intentionally fully local and works without internet access after download.
