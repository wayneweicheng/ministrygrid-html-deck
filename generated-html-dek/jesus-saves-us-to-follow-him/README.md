# Jesus Saves Us to Follow Him — HTML teaching deck

Offline-friendly 16:9 teaching deck for The Gospel Project: Kids, Easter Bonus Session 2.

## Source

- Lifeway Ministry Grid session: reviewed from the authenticated lesson resources
- Reviewed: 2026-09-06
- Content basis: Younger Kids and Older Kids Easter Leader Guides, session story poster, Big Picture Question resource, and Story Point resource.

## Launch

Open `index.html` in a browser. For local browser testing, run a simple static server from this folder:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000/`.

## Controls

- `←` / `→`: previous or next slide
- `Space`: next slide
- `Home` / `End`: first or last slide
- Click or tap the reveal buttons; focused buttons also open with `Enter` or `Space`

The optional source Bible Story Video was intentionally omitted so the pack remains lightweight and works without network access.
